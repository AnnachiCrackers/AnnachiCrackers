🔗 Google Sheets Database Setup — ஒரே முறை பண்ணினா போதும்!
1
Google Sheets open பண்ணுங்கள்
sheets.new → New blank sheet → Sheet name: Annachi Crackers
2
Row 1-ல் இந்த headers சரியா போடுங்கள்:
id name nameTa category price unit stock badge description emoji image
image column-ல் → direct image URL போடலாம் (Google Images-ல் இருந்து copy பண்ணி)
Empty-ஆ விட்டா → emoji காட்டும்
3
Row 2-ல் இருந்து products enter பண்ணுங்கள்
stock column-ல் exactly: In Stock / Limited / Out of Stock
badge column-ல்: Popular / New / Offer (or empty)
4
Apps Script open பண்ணுங்கள்
Sheet menu: Extensions → Apps Script → திறக்கும் editor-ல் இருக்கும் code-ஐ delete பண்ணி இந்த code paste பண்ணுங்கள்:
// ═══ ANNACHI CRACKERS — Apps Script ═══ // Products sheet + Settings sheet இரண்டும் handle பண்ணும் function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const prodSheet = ss.getSheetByName('Products') || ss.getActiveSheet(); const setSheet = ss.getSheetByName('Settings'); // ── Products ── const data = prodSheet.getDataRange().getValues(); const headers = data[0]; const rows = data.slice(1).filter(r => r[1] !== ''); const products = rows.map(row => { const obj = {}; headers.forEach((h, i) => { obj[String(h).trim()] = row[i] !== undefined ? String(row[i]).trim() : ''; }); obj.price = Number(obj.price) || 0; obj.id = obj.id || String(row[1]); return obj; }); // ── Settings ── const settings = {}; if (setSheet) { const sData = setSheet.getDataRange().getValues(); sData.forEach(row => { if (row[0] && row[1] !== undefined) settings[String(row[0]).trim()] = String(row[1]).trim(); }); } const output = JSON.stringify({ products, settings }); return ContentService .createTextOutput(output) .setMimeType(ContentService.MimeType.JSON); } function doPost(e) { try { const payload = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.getActiveSpreadsheet(); let setSheet = ss.getSheetByName('Settings'); if (!setSheet) { setSheet = ss.insertSheet('Settings'); setSheet.appendRow(['key', 'value']); } // Clear and rewrite settings const keys = Object.keys(payload); setSheet.clearContents(); setSheet.appendRow(['key', 'value']); keys.forEach(k => setSheet.appendRow([k, payload[k]])); return ContentService .createTextOutput(JSON.stringify({ success: true })) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({ success: false, error: err.message })) .setMimeType(ContentService.MimeType.JSON); } }
⚠️ Important: Sheet-ல் ஒரு tab-ஐ "Products" என rename பண்ணுங்கள் (sheet tab-ல் right click → Rename). Settings tab auto-ஆ create ஆகும்.
5
Deploy பண்ணுங்கள்
Deploy → New deployment → gear icon → Web app →
Execute as: Me  |  Who has access: Anyone → Deploy

6
URL இங்கே paste பண்ணி Save பண்ணுங்கள்:
7
index.html-ல் URL update பண்ணுங்கள்
index.html file open பண்ணி இந்த line தேடுங்கள்:
const SHEET_API_URL = ''; // உங்கள் Apps Script URL இங்கே போடுங்கள்
அதை இப்படி மாத்துங்கள்:
const SHEET_API_URL = 'உங்கள் URL இங்கே வரும்';
